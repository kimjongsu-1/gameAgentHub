# 《단맥》 1스테이지 이미지 제작 명세 — 금 간 봉인길

## 스테이지 정의

- 위치: 1장 `봉인의 금 간 밤` 첫 일반 구간
- 전투 시간: 30~60초
- 화면: 모바일 세로형 2D 방치 전투
- 분위기: 2040년 서울의 금 간 도로, 꺼진 네온, 보라색 침식 안개, 청백색 영맥 빛
- 등장 적: 금 간 잔령, 끊긴 보병
- 플레이 목표: 자동 공격과 `맥동 타격`으로 첫 침식 웨이브 격퇴

## A. 주인공 전투 이미지

### 디자인

- 이름 미정의 현대인, 성별 표현은 중성적인 청년형으로 시작한다.
- SD 2.5등신, 어두운 현대 캐주얼 복장, 장식은 최소화한다.
- 웅녀 혈통은 직접적인 곰 의상 대신 손등과 눈동자에 잠깐 드러나는 청백 영맥 문양으로 표현한다.
- 확정 전 비교용 정면 후보 5개와 권고안 1개를 만든다.

### 필수 애니메이션

- idle 16프레임
- walk 16프레임
- basic_attack 16프레임
- hit 8프레임
- death 12프레임
- 4x4 또는 프레임 수에 맞는 동일 셀 그리드, 투명 PNG, 6fps 기준
- 모든 프레임은 bottom-center pivot `(0.5, 1.0)`, 발 기준선과 몸 중심을 고정한다.

## B. 바리공주 길잡이 이미지

- 모바일 대화 UI용 반신 초상 1종을 기준으로 표정 변형 3종을 만든다.
- 표정: 차분한 기본, 급박한 경고, 부드러운 안도
- 검은색·남보라·청백색을 기본으로 하고 저승 장부 또는 작은 방울을 소품으로 사용한다.
- 전신 캐릭터가 아니라 재사용 가능한 반신 초상이며 투명 PNG로 만든다.
- 한국 전통 요소를 현대적으로 단순화하고 실존 종교 문양은 사용하지 않는다.

## C. 전투 배경 레이어

- 기준 해상도: 세로 1080x1920 비율
- 원경: 2040년 서울형 도심 실루엣, 꺼진 전광판과 깨진 네온
- 중경: 금 간 도로, 폐쇄된 지하철 출구, 부서진 가로등
- 전경: 청백색 영맥 균열과 작은 봉인 파편
- 오버레이: 보라색 침식 안개와 청색 혼불
- `far / mid / foreground / fog / spirit_fire` 레이어를 분리해 패럴랙스와 재사용이 가능해야 한다.
- 캐릭터가 서는 중앙 하단은 전투 가독성을 위해 복잡도를 낮춘다.

## D. 전투 이펙트

- `맥동 타격`: 청백색 원형 맥동이 주먹 또는 발밑에서 퍼지는 16프레임 투명 시트
- 일반 피격: 작은 청백 섬광 8프레임
- 황천 피격: 보라색 혼불 파편 8프레임
- 몬스터 소멸: 검은 입자와 보라 혼불이 안쪽으로 꺼지는 12프레임
- 바닥 영맥 균열: 대기 상태 16프레임 루프
- 6fps, 프레임별 중심·크기 고정, 과도한 화면 섬광 금지

## E. 보상 및 상호작용 아이콘

- 봉인 파편 아이콘
- 영맥 경험 구슬 아이콘
- 영맥석 아이콘
- 각 아이콘은 512x512 원본과 게임용 128x128 축소본을 만든다.
- 두꺼운 실루엣, 투명 배경, 텍스트 없음, 작은 화면에서 구분 가능해야 한다.

## 제외 항목

- 체력바, 버튼, 수치 패널, 스테이지 제목 표시는 Unity UI로 제작한다.
- 아직 획득하지 않은 구미호 아바타는 1스테이지 전투 이미지에 포함하지 않는다.
- 승인 전 에셋은 Unity 프로젝트에 반영하지 않는다.

## 품질 및 파이프라인

- 외부 AI API 호출 금지, 내장 이미지 생성 기능과 무료 로컬 도구만 사용한다.
- 모든 생성물은 프로젝트 작업 폴더에 저장하고 manifest를 작성한다.
- 투명화, 프레임 수, 그리드, 피벗 흔들림, 크기 변화, 잘림을 로컬 QA로 검사한다.
- 결과는 사용자 승인 대기에서 멈추고, 승인된 에셋만 게임개발 채팅으로 전달한다.
