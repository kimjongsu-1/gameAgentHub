# Sprite QA 규칙

## 입력 계약

- 기본 시트: 4열 × 4행, 정확히 16프레임
- 프레임 순서: 좌→우, 위→아래
- 모든 셀은 같은 크기
- PNG RGBA 권장
- 크로마키 입력은 실행 시 색상을 명시해야 함

## 자동 판정

- `PASS`: 기술 검사에서 문제 없음. 수동 일관성 검토 후 승인 요청 가능
- `FIXABLE`: 피벗, 여백, 중복, 크기 차이처럼 재정렬 또는 원본 보정이 필요한 문제
- `REDRAW`: 빈 프레임 또는 시트 구조 오류처럼 원본 재작업이 필요한 문제

`PASS`는 곧바로 게임 적용을 의미하지 않는다. 중앙 QA와 사용자 승인을 통과해야 에셋 상태가 `APPROVED`가 된다.

## 자동 수정 범위

허용:

- 명시된 단색 크로마키 배경 투명화
- 미리보기 GIF 생성
- 분석용 컨택트시트와 어니언스킨 생성

금지:

- 얼굴, 체형, 의상, 무기 재디자인
- 프레임 내용을 생성하거나 삭제하여 16장을 맞추는 행위
- 색상 재해석 또는 화풍 변경
